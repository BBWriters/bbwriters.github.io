# BB Writers, Inc.

Official public website for BB Writers, Inc. — writing, ghostwriting, editing, proofreading, eBook creation, and business content.

**Website address:** https://bbwriters.github.io/  
**Contact:** bbwritersinc@gmail.com

## First-time GitHub Pages setup

Visit https://github.com/BBWriters/bbwriters.github.io/settings/pages and choose:
- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/(root)**
- Click **Save**.

The site is fully self-contained in `index.html` and needs no paid tools, dependencies, hosting subscriptions, or build steps. It also contains `robots.txt`, `sitemap.xml`, and `.nojekyll` for search engines and static hosting.

## Google indexing

After GitHub Pages is live, add `https://bbwriters.github.io/` as a URL-prefix property in https://search.google.com/search-console/ and verify ownership using Google's HTML file option. Add the verification file to the repository root, submit `https://bbwriters.github.io/sitemap.xml`, and request indexing using URL Inspection. Indexing is up to Google and is not guaranteed.

## Editing

Change visible copy, styling, or the email link in `index.html`. The contact button opens the visitor's email program; this site does not collect or store form submissions. Keep the repository public for GitHub Pages free-tier hosting.
